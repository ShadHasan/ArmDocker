## Instruction for generating HTML
- Do not use style tag keep css inline
- Keep css and html simple and attractive. Feel free to use free and right to use commercially icon or generate.
- Do not use event listener and callback like OnClick etc.
- Put all the javascript in separate script.js
- Within script.js, keep all callback functions together with parameterized as much as possible.
- Within same script.js, after all callback functions all the event listeners are need to be added 
	with calling it relevant callback function or callback functions.
- It should be possible that any callback function might be calling other functions as well as
callback function might have other promise that need to be asynchronous listening. Such promise
need to be categorised as event and must be kept with event listener.
- Source this script.js in all the html pages at the end, within body tag.
